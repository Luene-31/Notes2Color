# Note2Color 取り扱い説明書（ユーザー向け）

この文書は、ブラウザで Note2Color を使うときの操作と画面の意味を説明します。

## できること

- **ピアノ鍵盤**で音を選び、その音に対応する色を混ぜ合わせた **結果の色** を表示します。
- **単音**でも、**和音（複数音）**でも構いません。
- **音声は出ません**（見た目の色だけです）。

## 画面の構成（上から順）

### 1. ヘッダー

アプリの説明と、説明用の基準として **A4 = 440 Hz** の表記があります（音は鳴りません）。

### 2. 表示色

現在選ばれている音（の集合）から計算した **混色後の 1 色** が表示されます。音が 1 つも選ばれていないときは、プレースホルダ（暗いグレーなど）になります。

### 3. 鍵盤（タップで選択／解除）

#### 鍵盤そのもの

- **白鍵・黒鍵**をタップすると、その音が **選ばれた状態** になります。もう一度タップすると **解除** されます。
- 選ばれている鍵は **網掛け** で強調表示されます。
- 表示されている鍵盤の範囲は画面内に記載のとおりです（例: A3〜B5）。

#### すべてクリア

鍵盤で選んでいる **すべての音** を一度に解除します。

#### ダイアトニック（C 長調・三和音）

**C 長調のダイアトニックな三和音**（C, Dm, Em, …）を、ボタン一つで鍵盤上に出せます。

- ボタンを押すと、その和音の構成音だけが選ばれます（以前の選択は置き換わります）。
- **同じボタンをもう一度**押すと、その和音の選択が **解除** されます（鍵盤が空になります）。

#### ルート音 × コード種類

**ルート音**（C4〜B4 の範囲で音名のみ指定）と **コード種類**（メジャー、マイナー、セブンスなど）を組み合わせて和音を選べます。

1. **ルート音** と **コード種類** をドロップダウンで選ぶ。
2. **表示（…）** を押すと、その和音が鍵盤に反映されます（従来の選択は置き換わります）。
3. **クリア** を押すと、鍵盤の選択がすべて解除されます。

コードの構成音は、画面に表示されている鍵盤の範囲に収まるように計算されています。

### 4. 混色モード（画面下）

選ばれた各音の色を、次のどちらのイメージで混ぜるか選びます。

- **加法混色（RGB・正規化付き線形和）**  
  光を重ねるイメージに近い混ぜ方です（既定）。
- **減法混色（CMY・乗算型）**  
  インクが重なるイメージに近い混ぜ方です。

モードを切り替えると、**同じ音の選択のまま**「表示色」だけが変わります。

## よくある使い方の例

- **単一の音の色を見る**: 鍵盤の 1 鍵だけをオンにする。
- **和音の「まとまった色」を見る**: 複数鍵をオンにするか、ダイアトニック／ルート×コードから和音を出す。
- **混色の違いを比べる**: 同じ和音のまま、画面下の **混色モード** だけを切り替える。

## 注意事項

- 色相は **可視光のスペクトルと厳密に一致するものではありません**（アプリ内の説明どおり、あくまで分かりやすい対応付けです）。
- **オフライン対応やデータ保存の保証**はアプリの仕様としては前提にしていません。利用環境（ブラウザ・端末）に依存します。
