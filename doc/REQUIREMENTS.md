# 要件定義：Note2Color Interpreter

## 1. アプリ概要

ユーザーが **ピアノの鍵盤** から音（半音単位）を選ぶと、各音に対応する **色** が決まり、複数音が選ばれたときは **混色** した結果が **色表示エリア（ボックス）** に表示される Web アプリケーション。

- **目的**: 「音（単音・和音）」を「色」に変換して直感的に眺められるようにする。
- **前提**: 音と色の対応は **物理法則による唯一の正解は存在しない**。本プロジェクトでは [SPEC_MAPPING_AND_MIXING.md](./SPEC_MAPPING_AND_MIXING.md) に定める **再現可能なルール** を正とする。

## 2. スコープ

### 2.1 含む

- 12平均律における **12音クラス**（ド〜シ＋半音／黒鍵）をカバーする鍵盤 UI。
- **単音選択** 時: 対応色をボックスに表示。
- **複数音選択** 時: 指定された混色モードに従い **1つの表示色** を算出してボックスに表示。
- **混色モード**: **加法混色（デフォルト）**、**減法混色（CMY ベース、オプション）**。
- **色相の説明**: 表示上は **RGB** または **H（色相）** と対応付けて説明できること（スペクトル帯 400–700nm は **近似対応** でよい）。
- **レスポンシブ**: PC のマウス操作と、スマートフォンのタッチ操作の両方で最低限使えること。

### 2.2 含まない（初期リリース）

- 実際のマイク入力や MIDI 機器からのリアルタイム演奏（将来拡張として記載のみ可）。
- 厳密な分光シミュレーション（波長ごとの積分など）。

## 3. 機能要件

| ID | 要件 |
|----|------|
| F-01 | 鍵盤上で **単一の音** を選択できる。選択中はその音に対応する色が **カラーボックス** に表示される。 |
| F-02 | **複数の音** を同時に選択できる（和音）。選択された音集合に対し、混色ルールに従った **1色** をカラーボックスに表示する。 |
| F-03 | **選択の解除**（同じ鍵を再度押す／専用のクリアボタンなど）ができる。仕様では **トグル** または **クリア** のいずれかを必須とする（実装で明示）。 |
| F-04 | **混色モード** を UI で切り替えられる: **加法（RGB）** / **減法（CMY）**（[SPEC_MAPPING_AND_MIXING.md](./SPEC_MAPPING_AND_MIXING.md) の定義に従う）。 |
| F-05 | 現在の **表示色** を **RGB（0–255）** および **HEX** で表示する（実装推奨）。**HSL/HSV の H** も併記すると理解しやすい（推奨）。 |
| F-06 | **基準音（A4 の周波数）** や **オクターブ表示範囲** が分かるようにする（鍵盤にラベル、またはヘルプテキスト）。 |

## 4. 非機能要件

| ID | 要件 |
|----|------|
| NF-01 | **クライアントのみ** で主要ロジックが完結する（静的ホスティングで動作）。個人情報をサーバに送らない。 |
| NF-02 | 主要ブラウザ（Chrome / Safari / Firefox / Edge）の **最新版** で動作すること。 |
| NF-03 | 初回表示および操作が **体感で重くない**（軽量なフロントエンドを志向）。 |
| NF-04 | **オフライン** でも開けるとよい（PWA 化は任意）。 |

## 5. UI / UX 要件

- **レイアウト**: 上部または中央に **カラーボックス**（十分なコントラストの枠線）。下部または横に **ピアノ鍵盤**。
- **鍵盤**: 白鍵・黒鍵の位置関係が分かる。**選択中の鍵** は色付けまたは枠で強調。
- **タッチ**: スマホで **誤タップしにくい** 最小タップ領域（目安 44×44px 以上）を意識する。
- **アクセシビリティ**: 色だけに依存せず、**数値（RGB 等）** を併記する。

## 6. 用語

- **音高**: MIDI では 0–127 の整数。本アプリでは表示用に **音名（C, C#, …）とオクターブ** と対応させる。
- **音クラス**: オクターブを無視した 12 種類（C, C#, …, B）。
- **加法混色**: 光の混色イメージ。本仕様では **RGB ベクトルの合成** で定義（詳細は仕様書）。
- **減法混色**: 色素の混色イメージ。本仕様では **CMY ベクトルの合成** で定義。
