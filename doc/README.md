# Note2Color Interpreter

音階（白鍵・黒鍵を含む12平均律）を色相空間に写し、単音・和音を色（表示）に変換する **Web アプリ** の仕様書置き場です。

## このリポジトリの目的

- ブラウザ（PC・スマートフォン）で動作するツールとして実装する。
- **音名／選択状態 → 色** の対応ルールと **混色** の数式を文書化し、別セッションの生成 AI や実装者にそのまま引き渡せること。

## クイックサマリ（実装の核）

- **入力**: ピアノ鍵盤 UI 上で選ばれた **MIDI 音高（0–127）** または **音名＋オクターブ** の集合。
- **1音あたりの色**: 推奨は **HSV の H を半音ステップで割り当て**（360° を12等分）、S・V は固定またはオクターブで微調整（仕様で固定値推奨）。
- **複数音**: **加法混色（RGB 空間）** をデフォルト。**減法混色** は **CMY 空間** で合成し RGB に戻すモードをトグルで提供。
- **出力**: 画面内の **カラーボックス** に結果色を表示。

詳細は [SPEC_MAPPING_AND_MIXING.md](./SPEC_MAPPING_AND_MIXING.md) を参照。
